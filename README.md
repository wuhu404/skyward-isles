# 云垣遗歌 · Skyward Isles

一款用 **Three.js + TypeScript + Vite + Rapier** 从零写成的 3D 第三人称动作冒险游戏。
你是一名旅人，从启程岛出发，穿过四片浮空群岛，取回三种风之能力，最终在风暴祭坛挑战「苍穹守卫 · 岚」。

所有模型、动画、材质、粒子、音效与音乐都是程序化生成的，仓库里没有任何外部美术或音频素材。

## 运行

需要 Node.js 18 以上，以及支持 WebGL2 与 WebAssembly 的桌面浏览器（建议 Chrome / Edge，键盘 + 鼠标）。

```bash
npm install
npm run dev        # 开发模式，浏览器打开终端里给出的地址（默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 本地预览生产构建
npm run build:single   # 额外生成 dist/skyward-isles.html：单个文件，双击即可在浏览器里运行
```

注意：仓库根目录的 `index.html` 引用的是 TypeScript 源码，直接双击打开不会运行，必须通过上面的命令启动；想要免安装运行请用 `build:single` 生成的单文件。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 / 方向键 | 转动视角（点击画面锁定鼠标） |
| 滚轮 | 调整镜头距离 |
| 空格 | 跳跃；空中再按一次二段跳；空中按住滑翔（需解锁） |
| Shift | 冲刺（消耗体力） |
| 鼠标左键 / J | 挥剑，连按三连击，第三击为重击 |
| 鼠标右键 / Q | 翻滚闪避（带无敌帧，消耗体力） |
| E | 风刃：朝准星方向发射，带辅助瞄准（需解锁） |
| F | 互动：风之碑休息存档、开宝箱、祭坛、读告示 |
| R | 饮用治疗药水（在风之碑休息时补满） |
| Esc / P | 暂停 |

## 游戏流程

| 区域 | 主题 | 玩法重点 | 获得 |
| --- | --- | --- | --- |
| 启程草原（启程岛 → 牧风丘） | 绿色草原、风车、小屋 | 基础战斗；推石块压住压板打开闸门 | 二段跳 |
| 落日遗迹（遗迹广场 → 风刃神殿） | 黄昏古城、立柱、秋色树 | 按正确顺序击打三块符文石启动移动平台 | 风刃 |
| 霜晶极境（霜原 → 极光台） | 夜晚冰原、极光、落雪 | 用风刃点亮水晶生成光之阶梯；限时点亮三颗水晶唤起上升气流 | 滑翔 |
| 风暴祭坛 | 雷云与闪电 | 滑翔跨越断崖，进入 Boss 竞技场 | 通关 |

- **敌人**：苔灵（跳跃追击、蓄力扑击）、石像卫士（霸体、砸地冲击波与横扫，出招后硬直）、幽光灵（悬浮远程、弱追踪光球、贴近时闪现）。
- **Boss「苍穹守卫 · 岚」**：三个阶段，依次加入砸地冲击波、横扫、弹幕、连段、冲锋和落雷风暴；出招后核心发亮时受到的伤害提高 50%。
- **成长**：星辉碎片累计到 12 / 30 / 55 枚时武器升级；宝箱和隐藏地点里有生命上限、体力上限、药水上限和七件远古遗物。
- **存档**：在风之碑休息、解开谜题、获得能力时自动写入浏览器 localStorage；死亡后从最近的风之碑重试；主菜单可以继续或开始新旅程。
- **设置**：画面质量、阴影、后期处理、视野、鼠标灵敏度、反转 Y 轴、镜头震动、三路音量、帧率显示、卡顿时自动降画质，全部即时生效并保存。

## 技术说明

- **物理**：Rapier 的 Kinematic Character Controller 负责玩家和地面敌人的移动、台阶与斜坡；相机用射线回缩避免穿墙；推箱是动态刚体，移动平台是运动学刚体并把位移传给站在上面的角色。
- **渲染**：平面着色的低多边形几何、跟随玩家的方向光阴影、实例化草地（顶点着色器里做风摆和玩家压弯）、点精灵粒子、Bloom + 色差 + 暗角 + 受击红晕的后期链；四个区域各有独立的天空、雾、光照和环境粒子，切换时平滑过渡。
- **性能与资源**：同类几何按 key 共享、道具合并成批、敌人和投射物全部池化（运行时不分配）；每个 Geometry / Material / 事件监听都登记在所属系统里，重开或返回菜单时统一释放。
- **音频**：Web Audio 合成的音效和按区域切换的环境音乐。

目录结构、坐标约定和模块接口见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 已知限制

- 只支持键盘鼠标，没有手柄和触屏操作。
- 生产包约 2.8 MB（gzip 后约 1 MB），其中大部分是内联的 Rapier WebAssembly。
